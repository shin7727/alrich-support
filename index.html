자주 묻는 질문

카드 문자를 자동으로 기록하려면 어떻게 하나요?
단축어 앱 → 자동화 → + → 메시지를 고르고, '메시지 다음을 포함'에 '승인' 또는 '취소'를 입력한 뒤 '즉시 실행'을 선택합니다. 동작 추가에서 '알뜰부자'를 검색해 '문자로 내역 기록'을 넣으면, 그 뒤로 오는 카드 문자가 자동으로 기록됩니다. 앱의 설정 → 문자 자동 기록에도 같은 안내가 있습니다.
문자 내용이 서버로 전송되나요?
아니요. 문자 원문은 기기 안에서만 읽고 저장합니다. 알뜰부자는 회원가입이나 은행·카드 계정 연결을 요구하지 않습니다.
폰을 바꾸면 내역을 옮길 수 있나요?
구독 중이라면 설정 → 동기화에서 iCloud로 백업하고, 새 기기에서 같은 Apple ID로 '가져오기'를 누르면 됩니다.
구독을 해지하거나 환불받으려면요?
구독 관리와 환불은 iPhone 설정 → Apple ID → 구독에서 할 수 있습니다. 구매를 복원하려면 앱의 상품 안내 화면에서 '구매 복원'을 누르세요.
